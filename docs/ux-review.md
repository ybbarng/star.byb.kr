# 서비스 UX 점검 (2026-10-21)

로컬 개발 서버(localhost:5025)에서 데스크톱과 모바일 너비(390px)로 모든 페이지를 둘러봤다.
한 줄 요약: **별 놀이터(게임)는 다듬어졌고, 처음 들어오는 문인 첫 화면과 플레이트 솔버는 옛 모습 그대로다.**
처음 온 사람은 첫 화면 → 플레이트 솔버 순서로 만나므로 이쪽을 먼저 고친다.

## 우선순위 1 — 첫인상과 핵심 기능

### 1. 첫 화면 (`src/app/page.tsx`)
- 너비가 `w-[500px]`로 고정돼 있어 모바일(390px)에서 왼쪽 글자가 잘린다.
- 그림이나 설명 없이 링크 세 줄만 있어서 무엇을 하는 사이트인지 알 수 없다. "Plate Solver"를 일반 사용자는 모른다.
- "2025-XX-XX Dev Seminar 발표자료"처럼 날짜가 빈칸인 채로 보인다.
- 모든 링크가 `target="_blank"`라서 같은 사이트 안에서도 새 탭이 열린다.
- **제안**: 별 놀이터와 같은 밤하늘 배경으로 바꾼다. 풀린 샘플 사진(별자리 선이 그려진 것)을 크게 보여 주고,
  큰 카드 두 개("내 사진 속 별자리 찾기", "별 놀이터")를 둔다. 발표 자료는 아래쪽 작은 링크로 둔다.

### 2. 플레이트 솔버 이름과 길 찾기
- 제목 "Plate Solver"와 단계 이름 "Plate Solving"이 영어다. "별 감지"도 낯설다.
  → 제목은 "사진 속 별자리 찾기", 단계는 "사진 고르기 · 별 확인 · 별자리 찾기"로 바꾼다.
- 첫 화면이나 별 놀이터로 돌아가는 링크가 없다 (게임에는 "← 별 놀이터"가 있다).
- 색이 게임과 다르다. 분홍 "파일 선택" 버튼과 평범한 검정 배경이라 다른 사이트처럼 보인다.
  → 게임 공통 틀(밤하늘 배경, 카드, 위쪽 바)을 같이 쓴다.

### 3. 1단계: 사진 고르기
- 샘플 목록이 파일 이름 그대로 보인다 (`20230904-nike-jeungseun-01.png`, `google-unknown.jpg`).
  → 작은 사진 카드에 "북두칠성 · 2023년 9월" 같은 이름을 붙인다.
- "사진은 기기 밖으로 나가지 않아요" 안내가 없다. 실제로 사진은 서버로 가지 않으니, 이 점을 알려 주면 업로드를 덜 망설인다.

### 4. 2단계: 별 확인
- 별을 찾는 동안 화면이 비어 있고 진행 표시가 없다.
- 용어가 어렵다: "마커 100개 · 흐릿 0개 · 83%", "또렷함 기준", "흐릿한 별 선택", "영역만 재검출".
- 빨간 "전체 삭제" 버튼이 가장 눈에 띈다. 실수로 누르기 쉽고, 되돌리기도 없다.
- 이 단계는 대부분 그냥 넘어가도 된다는 안내가 없다.
  → 위쪽에 한 줄 안내("찾은 별이 맞는지 보고 바로 다음을 눌러도 돼요")를 둔다. 도구는 "고치기" 아래로 접는다.

### 5. 3단계: 별자리 찾기
- 후보 목록이 기술 용어로 되어 있다 ("1. 매칭 27개, 신뢰도 26, FOV 36°").
  → 확신한 해는 "찾았어요! 큰곰자리 · 화각 36°" 한 줄로 보여 주고, 세부 내용은 접어 둔다.
- 마지막 단계인데 비활성 "다음" 버튼이 남아 있다. → "다른 사진으로", "별 놀이터에서 놀기"로 바꾼다.
- 촬영 시각, 경도·연도, 지평선 두 점, 달 찍기, "시각·장소로 풀기"가 한 판에 몰려 있다.
- **지평선·달 찍기는 2단계로 옮긴다** (사용자 지적, 2026-10-21).
  - 사진 위에 무엇을 찍는 일은 별 마커와 같은 종류인데, 지금은 2단계와 3단계에 흩어져 있다.
  - 지평선은 "시각·장소로 풀기"의 재료라서 풀기 전에 정해지는 편이 흐름에 맞다.
  - 3단계에 있는 이유는 코드 순서 때문이다. 자동 지평선과 촬영 시각 추정이 풀이 결과 옆에 붙어 있었다.
  - 바꾼 모습:
    - 2단계에서 자동으로 찾은 지평선을 초록 선으로 보여 준다.
    - "선택/이동" 옆에 "지평선"과 "달" 도구를 둔다. 선의 양 끝을 끌어서 고칠 수 있게 한다.
    - 3단계에는 "지평선: 자동으로 찾음 · 고치기" 한 줄만 남긴다.

## 우선순위 2 — 사이트 전체

### 6. 페이지 정보 (`src/app/layout.tsx`)
- `<html lang="en">`이다. 한국어 사이트라 `ko`로 바꿔야 화면 낭독기와 줄바꿈이 맞게 동작한다.
- 모든 페이지 제목이 "star.byb.kr"이고, 설명이 영어 "Find stars from Photo."다.
  → 페이지마다 제목을 둔다 (예: "SkyGuessr · star.byb.kr").
- 링크를 공유할 때 보일 미리보기 그림(OG 이미지)이 없다. 게임은 공유하기 좋은데 미리보기가 비어 있다.

### 7. 404 페이지
- Next.js 기본 영어 화면("This page could not be found.")이다.
  → 밤하늘 배경에 "길을 잃은 별이에요" 같은 문구와 첫 화면·별 놀이터 링크를 둔다.

### 8. 게임 사이 연결
- 게임에서 첫 화면으로 가는 길은 위쪽 "star.byb.kr" 글자뿐이다. 이 정도면 충분하다.
- 플레이트 솔버의 결과 화면에서 게임으로 가는 길이 없다 (5번에서 같이 해결한다).

## 우선순위 3 — 정리

### 9. 발표용 페이지 (`/database`, `/demo/*`, `/hash/*`)
- 제목, 설명, 돌아가는 링크가 없다. 발표 화면용이라 괜찮지만, 주소를 알면 누구나 들어올 수 있다.
  → 링크는 지금처럼 걸지 않는다. 검색에 걸리지 않게(`noindex`)만 한다.
- `/hash/feasibility`는 동작하지 않는다 (발표 준비 때 정하기로 함, journey TODO).

### 10. 남은 기본 파일
- `public/`에 Next 기본 그림(`next.svg`, `vercel.svg`, `file.svg`, `globe.svg`, `window.svg`)이 남아 있다. 지워도 된다.

## 게임 쪽 (대체로 좋다)

- 허브, 소개 화면, 시작 버튼, 소리 끄기가 모든 게임에서 같은 틀이다. 모바일 너비에서도 잘린 곳이 없다.
- 하늘 맞추기 소개 화면에 고를 줄이 두 개(단계·난이도)라서, 무엇을 골라야 하는지 잠깐 헷갈린다.
  → 단계는 지난 기록에 따라 자동으로 고르고, 난이도만 고르게 할 수도 있다.
- 생일 별자리는 날짜를 고르기 전에는 "찾기"가 비활성이다. 이건 괜찮지만, 오늘 날짜를 미리 골라 두면 한 번 덜 누른다.
- 아직 실제 화면으로 확인하지 못한 곳: SkyGuessr 어려움, 하늘 맞추기 2·3단계, 실제 핸드폰.

## 추천 순서

1. 첫 화면과 플레이트 솔버를 게임과 같은 틀로 다시 만든다 (1~5번, 지평선 옮기기 포함). 처음 오는 사람이 가장 먼저 만나는 곳이다.
2. 페이지 정보, 404, 미리보기 그림 (6~7번). 작고 금방 끝나며, 공유할 때 바로 효과가 난다.
3. 정리 (9~10번).

# 어안(fisheye) plate solving — 현황과 TODO

## 배경

초광각/어안 렌즈로 찍은 사진(예: `20220328-brice-Milky Way over Buzzvil.jpg`)은
직선투영(핀홀) 가정으로는 안 풀린다. 별이 중심에서 바깥으로 강하게 압축(어안)되기
때문이다. 사람이 라벨한 별 8개로 검증한 결과 **이 렌즈는 등거리 어안(r = f·θ)** 이고,
어안 카메라 모델로 맞추면 별자리를 픽셀 단위로 그릴 수 있다.

## 구현된 것

- **어안 카메라 모델** (`src/search/utils/fisheye.ts`): `r = f·(θ + k1·θ³)`, 광학중심
  (pcx,pcy) 자유. `fitFisheyeCamera`(격자 탐색 + 좌표하강 + 이상치 robust 제거),
  `refitFisheyeCamera`(warm), `projectFisheye`.
- **A — 라벨 기반 오버레이**: `fisheyeSamples.ts` + `PlateSolvingStep`이 라벨로 카메라를
  피팅해 별자리를 그린다. 은하수 RMS ~5.3px (Shaula 이상치 자동 제외).
- **B — blind 자동 풀이** (`src/search/fisheyeSolve.ts`): 로컬 quad는 어안이어도 모양이
  보존된다는 점을 이용. 매칭 → 별별 투표 → 고표 시드 피팅 → inlier 정밀화.
  **합성 어안: 깨끗·가짜50%에서 광축오차 0.00°.**

## TODO — 진짜 은하수처럼 노이즈 심한(≈90%) 사진의 blind 돌파

진짜 은하수 검출은 1315개(진짜 ~138, 노이즈 ~90% + haze). 현재 blind는 24개가 자기들끼리
일관된 **틀린** 해로 수렴해 실패(광축 114° 빗나감). 합성 50% 노이즈는 되지만 90%는 한계.

시도할 것:

1. **유의도 게이트** — blindSolveFisheye가 inlier 수만 보고 채택한다(24개 우연 일치도
   통과). "이 inlier 수가 우연 대비 유의미한가"(FOV 내 별밀도 × 허용오차 면적 대비)를
   계산해, 우연 수준이면 해 없음으로 처리. (기존 rectilinear solveCore의 significance와
   동일한 발상.)
2. **다중 시드** — 고표 상위 한 묶음만 시드로 쓰지 말고, 서로 다른 시드 후보를 여러 개
   잡아 각각 inlier 확장 → 가장 inlier 많고 유의한 해 채택(RANSAC식).
3. **haze/노이즈 영역 제거** — 검출 전처리로 은하수 띠·건물 같은 구조적 노이즈 영역을
   제외하거나, 모양(fwhm/elongation) 필터로 또렷한 별만 남겨 노이즈 비율을 낮춘다.
4. **밝기/모양 사전 필터** — 입력을 또렷한 별 위주로 줄여 노이즈 비율을 50% 이하로.

목표: 노이즈 90% 사진도 라벨 없이 자동으로 풀거나, 최소한 "확신 못 함"을 정직히 반환
(틀린 해를 확신하지 않기).

## 관찰 (2026-10-20) — 실제 사진에서 투표가 너무 느슨하다

지면을 뺀 위쪽 영역(100/75/55/45%)과 입력 크기(60/100/150)를 바꿔 은하수에 blind 풀이를 돌렸다.
모든 조건에서 실패했는데, 실패 모양이 같았다.

- `voted`(투표로 정체를 확정한 별 수)가 **항상 입력 수와 같다**(60개 넣으면 60, 150개면 150).
  모든 별이 "최다표 ≥ 3"을 넘는다는 뜻이다. 로컬 quad 후보가 별마다 많아서, 우연한 표도 3표를 쉽게 넘는다.
- `inliers`는 항상 시드 크기(24) 그대로이고 `rms`는 `Infinity`다. 시드 피팅 결과로 투영하면 맞는 별이
  6개도 안 돼 정밀화 루프가 한 번도 돌지 않았다.

→ 노이즈 비율보다 먼저 **투표 기준이 실제 사진에서 정체를 가려내지 못하는 것**이 문제로 보인다.
다음에 볼 것: 최다표가 2위 표보다 충분히 많은지(표 차이/비율) 기준, 별당 후보 수에 비례한 기준,
시드 24개 중 서로 기하적으로 맞는 부분집합만 고르는 RANSAC. 어안 판정에도 log-odds를 써서 "확신 못 함"을 정직하게 낸다.
